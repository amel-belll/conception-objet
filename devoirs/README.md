# Dossier de rendu
Vous déposerez ici les documents qui vous sont demandés dans certains devoirs (pdfs etc.). Prenez soin de faire le commit dans la branche `main`. Et surtout n'oubliez pas de faire un `push`

# Procédure
- Placer les fichiers dans ce dossier
- Ajouter les fichiers `git add ./devoirs` ou via votre IDE
- Faites un commit `git commit -m "rendu devoir X..."` ou via votre IDE
- Faites un push `git push`

Vérification : lorsque vous allez voir dans votre repository sur github vos nouveaux fichiers apparaissent dans ce dossier.

L'heure de votre commit fait foi.

***Si vous rencontrez un problème, envoyez-moi les documents par email.***
